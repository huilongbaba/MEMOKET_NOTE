## 铁律（每一批都适用）

1. **先能看见，再动手。** 阶段 0 不改任何行为，只把数记下来。
   没有数的改动无法证明有效，也无法回退判断。
2. **能用代码判准的，不交给模型。**（`checks/__init__.py` 的老规矩）
3. **判据宁可窄一点**，误伤比漏报贵；阈值一律在**真实产出**上量，不拍脑袋。
4. **闸跑绿不等于闸有用**——每条新判据都要**突变验**（把修复撤掉必须变红）。
5. **不改 `loop.py`。** 全部落在 middleware / checks / tools / prompts / 落库。
6. **每一批都跑全量闸**：`npm test`（tsc + eslint + vitest + check 脚本）、
   后端 `pytest`。红了就先修红的。
7. **质量优先于省钱。** 任何一条让产出变差，退回去。

`backend/scripts/` 下面躺着：

| `editing_quality_bench.py` | 已知缺陷 → 看编辑**修不修得掉**，自动判定 | `editing_bench_log.jsonl` + 36 份产出 |

| `harness_stress_test.py` | 大量真实数据跑，记**每一轮**的 evaluate 结果，可断点续跑 | **`harness_stress_log.jsonl`，200 行** |
| `agent_tools_ab.py` | A/B：agent 自主检索 vs 预装配检索 | `agent_tools_ab.jsonl` |

**我在 `harness-effect-plan.md` 里写「每一轮的分数跑完就没了，这个问题在现有数据里
无法回答」——那句话对产品代码路径成立，对这个仓不成立。** 200 轮的每轮分数就在那儿。

### 用那 200 轮立刻量出来的三个数（比之前所有结论都硬）

```
第 N+1 轮相对第 N 轮，最弱维度：
    变好  41 (33%)      持平  81 (65%)      变差  3 (2%)
总分逐轮：上升 39   持平 64   下降 25
```

**65% 的轮次，最弱维度一动不动。** 这比「执行器不对」更严重——
大多数轮次**什么都没发生**，而每一轮都花了检索 + 续写 + 打分三次模型调用。

各维度按轮次的均分：

| 轮次 | beat_cov | factual | **non_rep** | spine | n |
|---|---|---|---|---|---|
| r1 | 1.91 | 1.72 | **1.14** | 1.95 | 66 |
| r2 | 1.86 | 1.74 | **1.18** | 1.95 | 57 |
| r3 | 1.91 | 1.81 | **1.08** | 1.96 | 46 |
| r4 | 1.71 | 1.76 | **1.24** | 1.88 | 17 |

- `non_repetition` **跨轮几乎不动**（1.08–1.24）——正是 `_NON_REPETITION` 注释里
  记着的「稳在 1.3 下不来」。**这条我在第 763 轮刚做的段内查重，正好可以拿这套台子验前后。**
- `spine_fidelity` 1.88–1.96 **封顶**，印证了「对着一个没人验过的计划打分，太容易满足」。

## 200 轮里做什么、不做什么

**做**（约 34 条）：阶段 0 ✅ → 1 → 2 → 3 → 5 → 4 → 6 → 7 → 8 → 10。

**明确推到 200 轮之后**：

- **9.2 一致率**、**9.4 judge 模型槽**、**10.3 重新校准**——
  它们都依赖 **9.1 采集用户编辑**攒出数据，而那要跑一段时间。
  **9.1 本身要尽早做**（采集没有风险），但**别急着用它调参**：
  样本不够时按它调，比不调更糟。
- **Re3 的「同位置多候选重排」**（longform 建议六）：会让每轮写作调用翻 N 倍，
  等阶段 0 的每轮数据攒够，拿数据判断「一轮值不值得花 2–3 倍」再说。
- **`Weaver` 式按验证器准确率加权**：依赖 9.2。

## 不做

- 不换 memory engine（就用 kite）。
- 不引入 DSPy / GEPA / Mem0 / Letta 任何一个当依赖。
- 不加新评分维度（已有 25 个，问题在执行器和上下文，不在指标）。
- 不做自动删重复、不做跨跑自动回滚（只报，不替用户决定）。
- 不上 token 级控制器（走 HTTP 接口，没有解码控制权）。
- 不为「写得更长」优化。
