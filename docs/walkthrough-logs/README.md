# 走查日志：**留在这儿，为的是下一批能逐行 diff**

P83 的走查那一节末尾逐字写着：

> ⚠️ **这一批没能逐行 diff 到 P80 的原始日志**：P80 那份跑在它自己的 scratch 里，
> 这一批开工时**已经不在了**。…… 下一批要么把上一批的日志留在**固定位置**，
> 要么就别在任务书里写「逐行 diff 判」。

**这就是那个固定位置**（P85 C①）。一批一个目录（`p85/`、`p86/`…），
一步一个文件，文件名按走查表的顺序编号 + 身份 + 步骤脚本名。

## 存进来之前先洗一遍

原始日志里每批都会变的东西有一大把（note id、端口、pid、时间戳、今天是几号、
截图名的批次前缀、scratch 的绝对路径）。原样存进来，下一批 `diff` 出来是**满屏红**——
而一份永远全红的 diff 不是对账。所以存进来的是洗过的：

```sh
cd frontend
node scripts/walkthrough/normalize-log.mjs --today <这一趟跑的那天> \
  --out ../docs/walkthrough-logs/p86 <scratch 里那些 *.txt>
```

**洗掉了哪几类、哪几类一个字都没洗**，逐条写在 `normalize-log.mjs` 的抬头里。
一句话：**每批必变的洗掉，判据（字数 / 段数 / 项数 / 圆点 / 逐字文案 /
语料里的日期 / 亚像素坐标）一个字不动。**

「洗干净了没有」有闸看着：`node scripts/walkthrough/normalize-log.mjs --selftest`
（在 `npm test` 里）——例 / 反例 20 条，外加把**这个目录底下每一份**都扫一遍，
剩了 note id / 绝对路径 / 端口 / 时间戳**当场红**。

## 下一批怎么用

```sh
diff -u docs/walkthrough-logs/p85/06-old-b1old.txt docs/walkthrough-logs/p86/06-old-b1old.txt
```

差异**不等于**回退：换了一份 udd、换了种子标题、语料里多了一篇，都会让某些行变。
这份 diff 的用处是**把「要看一眼的那几行」缩到几十行**，判还是人判。

## 这儿存不了什么

* **截图**：不进 git（一批几十张 PNG）。它们在那一批自己的 scratch 里，台账记名字。
* **go.sh 那一层的输出**（起壳、端口对照、收摊）：那是量具自己的话，不是走查的读数。
* **真库**：一个字节都不进来。这些日志里凡是 note id 一律已经洗成 `<ID12>`。
* **第一批就能 diff**：不能。`p85` 是第一份，**跨批逐行 diff 从下一批起才做得了**——
  照实记，别把「留了地方」说成「已经对过账」。

## 第一次真做成是 P87（`diff p85 p87`）

**做成了，而且第一趟就抓到两笔**（细节在 `docs/TRACELOG-product.md` 的 P87 A 节）：

* **一条归一化的洞**：`/api/health` 回的 `{"pid":26273,…}` 里那个 pid **整整一批没洗掉**
  ——原来那条规则要求 `pid` 后面紧挨着 `=` / `:` / 空格，而 JSON 里中间隔着一个引号。
  它在 diff 上是**唯一一条纯噪声**。补规则 + 补「洗完不许剩下什么」那一侧 + 喂了
  正反例（含 `rapid` 这个不许洗的），并且**把 `p85` 那一份也重洗了一遍**
  ——新规则只管新日志的话，旧日志上那条噪声会永远躺在 diff 里。
* **一处台账跟日志对不上**：P85 的走查表把老用户 900px「横向溢出」记成 **0**，
  而 P85 **自己那份日志**（`p85/06-old-b1old.txt:96`）写着 **1**（溢出的是
  `note-tab active`「P58 走查（可删）×」）。**「台账上的数」和「日志里的数」是两把尺**
  ——这正是把日志留下来的全部意义：散文错了没人看得出来，逐行 diff 看得出来。

**做成之后的第二条经验**：`diff` 出来 78 行变动，**差异为 0 从来不是目标**。
能解释的差异分三类，每一类的处置不一样：

| 类 | 这一批占了多少 | 怎么处置 |
|---|---|---|
| **走查入参 / 素材不同**（截图前缀、种子标题、udd 是不是全新的） | 大头 | 照实记来源，**不追平** |
| **归一化没洗干净** | 2 行 | **补闸 + 喂反例 + 把旧的那一份也重洗** |
| **走查自己的随机性**（⌘K 候选序号、右栏刷没刷到） | 若干 | 记在案，看它下一批还在不在 |

解释不了的**当场记成问题**（这一批有一条：⑩ 那一格「润色」之后右栏没摆出「改动」页签，
而库里那一层两批**逐字节相同**）。
