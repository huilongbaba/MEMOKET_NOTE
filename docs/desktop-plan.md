# MEMOKET_NOTE 桌面版：照 Trilium 重做界面 + Electron 打包

> 目标不是「像 Trilium」，是**拿到 Trilium 那套结构带来的东西**：多标签、
> 真正的笔记树、左侧启动栏、右栏放上下文、状态栏。我们现有的功能
> （harness / 知识库 / skill / 无限续写）一个都不丢。

## 许可证

Trilium 是 **AGPL-3.0**。仓库主人已明确本项目也会开源，因此直接复用它的
代码（CSS 主题、控件实现）是可以的。**代价要写在这里，别让以后的人踩到**：

- 本仓库必须以 AGPL-3.0 发布，源码要对**通过网络使用它的人**可得
- 任何闭源分发（包括只提供 SaaS）都不成立
- 复用的文件要保留出处，见 `docs/third-party-notices.md`

## 三个架构决定

### 1. 后端不动，Electron 把它当子进程拉起来

FastAPI + KITE + sqlite 这一套 17k 行是产品的核心，不重写。Electron 主
进程负责起停它：

- 开发：直接用 `backend/.venv` 里的 python
- 发布：PyInstaller 打成单文件，跟 app 一起装

**这是整件事里唯一有真实失败风险的一步，所以先做。** 界面再漂亮，装不
上就没有意义。

### 2. 前端仍然是 React 19 + Vite + CodeMirror 6

Trilium 的客户端是 **Preact + JSX**（不是我一开始以为的自研非 React 框架，
它的 jQuery widget 层是遗留部分），而且编辑器同样是 CodeMirror——所以它的
布局和控件搬过来是可行的，不用把我们的编辑器扔掉重来。

直接拿的：`theme-next/` 的 CSS（shell / base / forms / dialogs）、图标。
照着重做的：布局的 React 结构、树、标签页。

### 3. 界面结构照 Trilium 的桌面布局

```
┌──┬────────────┬──────────────────────────────────┬────────┐
│启│ 快速搜索    │ 标签页                            │        │
│动├────────────┼──────────────────────────────────┤ 右栏   │
│栏│ 笔记树      │ 标题行（图标·标题·操作）           │ 大纲   │
│53│            ├──────────────────────────────────┤ Agent  │
│px│            │ 编辑器（CodeMirror）              │ 修订   │
│  │            │                                  │ 知识库 │
├──┴────────────┴──────────────────────────────────┴────────┤
│ 状态栏                                                     │
└───────────────────────────────────────────────────────────┘
```

启动栏放我们自己的入口：知识库 · Skill · 无限续写 · 设置 · 用户切换。

## 阶段

| 阶段 | 内容 | 判据 |
|---|---|---|
| A | Electron 外壳 + 拉起后端 | 打包出的 .app 双击能用，不依赖本机装 python |
| B | 布局外壳（启动栏/树/标签页/右栏/状态栏） | 现有功能全部还在，只是换了位置 |
| C | 把现有面板搬进新外壳 | 22 个组件逐个归位 |
| D | 打磨 + 测试 | 两端测试全绿；真机点得通 |

## 不做什么

- **不移植 Trilium 的数据模型**（笔记树用属性/克隆/branch 那一套）。我们的
  笔记是文件夹 + 笔记两层，硬套它的模型等于重写后端。树是**展示层**的事。
- **不移植它的富文本编辑器**（CKEditor）。我们是 markdown + CodeMirror，
  这是产品的既定选择。
- 不做移动端、web clipper、协作、加密——那些是 Trilium 的产品范围。
