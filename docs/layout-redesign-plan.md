# 布局重梳理：把它做成一个「笔记工具」，不是一个「按钮面板」

> 触发：用户看完打包版第一眼——「你这个布局根本就不是一个 note 工具」。
> 对照 Trilium 的 desktop_layout.tsx 逐块重排，每个元素只允许有一个家。

## 0. 诊断：现在为什么不像笔记工具

截图（2026-09-11）里，标题到正文之间隔着：ribbon 条 → 写作骨架整块（自动展开，
占半屏）→ 两行 AI 按钮 → 格式工具栏。**正文在第五层。** 一个笔记工具的正文
应该在标题正下方。

右栏更乱：常驻的「相关记忆」（42% 高）+ 标签条 + 「知识库」面板里又塞了
浏览按钮、统计、阶段回顾、搜索框、个人偏好——五种不相干的东西叠在 300px 里。

图标是 emoji 和方块字符（🧩 🚀 ⚙ ▢ ▣ ◆ ▤），launcher 没有 logo。标题栏写着
「未命名」而树上写着首行——同一篇两个名字。

根因：每加一个功能就往正文上方或右栏里「再放一块」，没有一个「每个元素只有
一个家」的总图。

## 1. 原则

1. **正文优先**：标题正下方就是正文。标题和正文之间只允许一条 36px 的 ribbon 条。
2. **每个元素一个家**：同一件事不在两处出现（「知识库」现在出现在 ribbon、
   右栏、树、launcher 四处）。
3. **AI 能力是正文的浮动按钮**（Trilium FloatingButtons）：在正文右上角，
   跟正文一起、不占正文的行。判据 1 「一个能力一个按钮」不变。
4. **右栏只有标签，没有常驻区**：Trilium 的右栏就是标签；「相关记忆」做成
   默认标签，不再是压在所有标签上面的常驻块。
5. **真图标**：Boxicons（Trilium 同款，MIT），不用 emoji / 字符画。
6. **左栏的树是唯一的导航**：知识库的浏览 / 总览 / 图 / 回顾全是树上的节点。

## 3. 每个元素去哪（唯一的家）

| 元素 | 现在在哪 | 去哪 | 为什么 |
|---|---|---|---|
| **写作骨架**（spine / beats / 覆盖） | ribbon 自动展开，占半屏 | 右栏「计划」标签（跟 harness 运行日志合并：计划 + 执行 = 一个面板）；harness 跑起来时右栏自动切到它 | 判据 3「计划要看得见」——在**右栏一直看得见**比把正文顶下去好 |
| **magic tap 续写 / 智能续写 / 打磨** | 正文上方一行大按钮 | 正文右上角浮动按钮：`✦ 续写`（magic tap）、`🤖 智能续写 ▾`（下拉：打磨 / 逐轮我来定 开关）| Trilium FloatingButtons 的位置；两件主能力保留文字，其余收进下拉 |
| **逐轮我来定** | 复选框挤在按钮行 | 智能续写下拉里的开关 | 它是智能续写的参数，不是独立能力 |
| **录音插入 / 录音入库** | 浮动胶囊两个 | 浮动按钮 `🎙 ▾`（下拉：插入正文 / 存入知识库） | 一个麦克风，两个去处 |
| **存入知识库** | ribbon ⋯ 和「知识库」标签里 | ribbon「引用」标签里（唯一）+ ⋯ 菜单快捷 | 它是「这篇跟知识库的关系」的一部分 |
| **格式工具栏** | 正文上方常显 | ribbon「格式」标签，**默认展开**（Trilium 的 classic toolbar 就是这么放的） | 用户要它一直在，ribbon 默认展开就是一直在 |
| **ribbon「知识库」** | ribbon | 改名「引用」：引用了哪几条、摄入状态、找不到的、也引用于 | 「知识库」这个词只留给树上那个节点 |
| **路径 / 信息** | ribbon | ribbon，不变 | 语义上就是 ribbon 的（Trilium NotePaths / NoteInfo） |
| **相关记忆** | 右栏常驻 42% | 右栏「记忆」标签，默认选中 | 右栏只有标签 |
| **目录** | 右栏标签 | 右栏「目录」标签 | 不变 |
| **运行** | 右栏标签 | 合并进「计划」 | 见第一行 |
| **修订 / 来龙去脉** | 右栏标签 | 右栏「修订」「脉络」标签（有内容才出现） | 不变 |
| **右栏「知识库」面板**（浏览/统计/阶段回顾/搜索/偏好） | 右栏标签 | **拆掉**：浏览→树「知识库」节点；统计→「总览」节点；阶段回顾→「定期回顾」节点；搜索→⌘K；个人偏好→设置里的一节 | 五件不相干的事叠在 300px 里 |
| **浏览** 按钮 | 右栏 | 删（树上就是） | 重复入口 |
| **标题「未命名」** | 标题行 | 标题为空/占位时，标题行显示首行作占位文字（灰），跟树、标签同一个 displayTitle | 一篇两个名字 |
| **字数** | 状态栏 | 状态栏右端 + 信息标签 | 不变 |
| **launcher** | emoji | logo（顶部）· 新建 · 搜索 · 导入 ｜ 底部：Skill · 无限续写 · 设置 · 折叠 | 真图标 |
| **树图标** | ▢ ▣ ◆ ▤ | Boxicons：笔记 bx-note / 有子节点 bx-folder / 知识库 bx-brain / 主题 bx-hash / 实体 bx-user / 月份 bx-calendar / 会议 bx-conversation / 事实 bx-bulb / 总览 bx-bar-chart / 图 bx-network-chart / 回顾 bx-history | 跟 Trilium 同一套字体图标 |

## 4. 图标与 logo

- 图标库：`boxicons`（npm，MIT，Trilium 同款），Vite 打包字体，离线可用。
- Logo：一个 SVG 标记——一页笔记 + 一枚事实菱形（跟 dmg 图标同一个母版），
  launcher 顶部 30px；app 图标同款重出。
- 尺寸：launcher 图标 22px；树图标 16px；ribbon / 右栏标签图标 14px + 文字；
  浮动按钮 16px 图标 + 12px 文字。
- 色：图标用 `--left-pane-icon` / `--muted`，激活走 `--main-fg`，不用彩色 emoji。
