# 桌面顶部灵动岛

桌面版默认只有屏幕顶部一个灵动岛，没有左右侧入口。首次展开进入笔记，记录、接入资料和调用 AI 是主要使用路径；暂存架、知识库与专注通过顶部的分段标签进入。AI 收在笔记编辑器的正文右键和底部菜单中，暂存架只负责临时物品的放入、预览和取回，不常驻 AI 入口，也不会自动处理暂存材料。完整笔记库是长文编辑、搜索、整理资料和配置服务的次入口；其中的今日工作台、编辑器与知识库继续保留。

浮窗跟着桌面端的外观走（设置 › 外观：跟随系统 / 浅色 / 深色，经 `nativeTheme.themeSource` 变成岛上的 `prefers-color-scheme`）：深色时是一块纯黑（#000）的不透明物体，与刘海连成一体；浅色时是同一块物体换成白底黑字，叠层与发丝线换成黑色的 5–12%，主按钮变成黑色实心胶囊，靠一圈 1px 内侧暗边从浅色壁纸上分出来。令牌只有一套（`--desk-*`），浅色值写在 design-tokens.css 的 light 媒体查询里。深色：不描边、不投影（原生窗口与外形等大，外投影本来会被裁掉），只有一圈内侧的 1px 亮边；收起时底部是 22 px 的胶囊圆角，展开后随弹簧过渡到 28 px。深度靠黑底上的白色叠层与 8% 的发丝线，颜色只保留一个强调色（提亮的品牌紫），只给「活着的状态」：计时弧、AI 进行中的点、拖放的目标、键盘焦点；主按钮是唯一的白色实心胶囊。顶栏与收起的药丸同高（44 px），左侧标记停在同一个位置，中间是一枚分段控件（笔记 · 暂存箱 · 知识库 · 专注），滑块按序号平移；四列物品保留真实内容缩略图，边框和操作在悬停或键盘聚焦时出现，避免把暂存架做成功能面板。令牌全部在 `frontend/src/design-tokens.css` 的 `--desk-*` 一节。

## 展开与收起

鼠标在顶部停留 **120 ms** 后展开，悬停不抢走当前应用的输入焦点。初始面板是笔记，之后保留当前面板；点击「笔记」或按 `⌘⇧N` / `Ctrl+Shift+N` 可直接打开笔记编辑器，AI 从正文右键或底部紧凑菜单调用。系统快捷键需要桌面应用正在运行，且注册未被其他应用占用。

展开后，鼠标移到顶部「笔记」「暂存箱」「会话」「待办」标签即切换面板，无需点击，也不会抢输入焦点；分段控件的滑块随之平移，途中改变目标只是重新定向。点击与键盘进入仍保留。快速往返以最后停留的标签为准，草稿与后台 AI 任务不受切换影响。拖着文件经过标签或系统文件选择器打开时暂停悬停切页，左右投放目的地保持稳定。

鼠标离开 **260 ms** 后自动收起，期间重新移入会取消收起。草稿、输入框焦点、文字选区和内容预览不会自动固定浮窗，收起后内容原样保留；只有点击「固定展开」才持续停留。唯一的例外是**输入法组合进行中**：候选窗抢走窗口焦点引起的失焦不触发收起，岛不能在半个词底下折走；鼠标离开照常收起。拖放、选择文件或保存普通笔记期间短暂延后，操作结束后继续收起，无需再次移动鼠标；刚收到的暂存物品保留 **3 秒** 到达反馈。AI 的连接、生成和结果保存独立运行，不锁定导航、正文编辑或收起。收起或切换暂存架／待办会隐藏任务界面，保留正在执行的请求；再次展开不会重复调用模型。

展开与收起使用 `requestAnimationFrame` 驱动的临界阻尼弹簧，没有固定播放时长。当前弹簧响应参数为展开 `0.34 s`、收起 `0.28 s`，它们控制响应速度，不是动画结束时刻。途中反向会保留当前几何与速度，更新目标后继续运动。外层轮廓改变大小，内部内容区域保持固定尺寸，通过分层透明度显隐，避免文字随轮廓反复换行或缩放。系统开启减少动态效果时直接切换状态。

原生窗口在展开前提供完整画布；收起时等待渲染层报告弹簧到达目标，再缩回小窗。若未收到完成通知，主进程以 **1,000 ms** 超时兜底；这不是动画时长。途中重新展开会取消旧的收起操作。

原生界面是一个无边框、置顶的 Electron 窗口。初次显示不抢焦点，macOS 默认隐藏 Dock 图标；菜单栏可重新显示或隐藏灵动岛、打开完整笔记库、退出应用。打开完整笔记库会显示 Dock 入口，关闭笔记库窗口时隐藏该窗口，灵动岛继续运行。

## 日常使用路径

| 入口 | 实际行为 |
|---|---|
| 笔记 | 默认入口，展示标题与正文编辑器，直接记录、粘贴内容或接入文件附件，明确保存后加入笔记库；本机草稿与附件保留。 |
| 拖入文件或图片 | 内容让位，只剩三个去处：左「附到笔记」（正在写的这一篇）、中「交给 Claude」（复制进会话工作目录的「附件」，在输入行上方列成小胶囊，随下一句一起发）、右「放入暂存箱」（保留独立副本）。左右两个位置不动，新来的放中间；指针在哪一格哪一格亮起，其余退到 55%。释放时只执行选中的用途，移出即取消；松开后岛切到那个去处，底部一行说结果，收起时药丸说同一句（「已交给 Claude · 2 个文件」）。拖的是文字时仍直接进暂存箱。图片作为附件时显示实际缩略图。 |
| 暂存架 | 仅负责暂存与取回。拖入时选择右侧目的地，或用「添加」菜单选择文件、剪贴板、窗口、文字与链接；有物品时展示四列缩略图，搜索按需展开。 |
| 正文 AI 菜单 | 右键正文或点击底部 AI 按钮，按需调用整理笔记、续写、提炼要点、图表、表格、待办。优先处理选中文字，无选区时处理当前正文，空稿使用显示的剪贴板候选；菜单标明本次范围，原草稿不会被 AI 结果覆盖。六项功能不在主页常驻铺开。点击后只显示正文下方的一行后台任务状态，完成不切换页面；结果直接写进正文——续写只写 3–5 行到自然停顿处，整理替换所处理的范围，其余动作插在范围之后（无选区时追加到末尾）——底部留一行「已写入 N 行 · 撤销」，撤销只拿掉写入的那一段。 |
| 剪贴板候选 | 直接在正文编辑区内以浅色文字预浮现，不再展示独立卡片。空稿或光标位于正文末尾时，按 Tab 接入当前快照；继续输入或按 Esc 忽略。 |
| 待办 | 今天要做的事（面板 id `tasks`）：与工作台首页「今日重点」读写同一份本机列表（`workspaceStorageKey(user, 'tasks', day)`），另一扇窗口的改动经 storage 事件即时同步；每次改动先读最新存档再按 id 增删改，不会盖掉别的窗口刚写的。勾选完成、回车添加、悬停删除；前几天没做完的一行「移到今天」。没做完的在上，做完的沉到下面变淡。 |
| 相关记忆 | 写作时正文下方一行「N 条相关记忆」：空闲 900 ms 后按光标所在段落向知识库做零模型的词法召回（`POST /api/memory/recall`），最多三条；正文里已引用的不再出现。点开才展开，绝不自动弹出、不抢焦点；「引用」把事实原文连同 `[事实 id]` 出处标记插入光标处，与完整笔记库的引用格式一致。知识库为空、请求失败或没有命中时这一行不出现。 |
| 会话 | 面板 id `agent`：和 Claude Code 直接对话，不用切到终端。主进程以无头方式运行本机已安装、已登录的 `claude`（`-p --output-format stream-json`，每轮一个子进程，`--resume` 接上同一会话），读写类工具（Read / Write / Edit / MultiEdit）按工作目录的绝对路径限定，Glob / Grep 只是找，不许跑命令，也不带用户配置里的 MCP 连接器（`--strict-mcp-config`）；工作目录固定在 userData/agent/workspace（不放在 companion/ 下，因为暂存箱拒收自己私有目录里的文件）。拖进来的文件复制到 workspace/附件/，提示词末尾附上路径清单，Claude 直接读。顶部选模型（默认 / Opus / Sonnet / Haiku）与最近会话；回复流式出现，悬停有「引用到笔记」（插到正在写的笔记光标处并切回笔记）「存为笔记」（存好后同样自动进知识库）「复制」；智能体写出的文件逐行列出，「放入暂存箱」走和拖入文件同一条复制路径。没找到或没登录 `claude` 时只有一句说明和「重试」。会话与消息记在 userData/agent/ 下。 |
| 拿主意 | 两个入口。**双击 ⌃（主入口）**：一个原生辅助进程（`helpers/modtap.swift` → `dist/modtap`，`npm run build:helpers`，辅助功能权限跟着启动它的应用走；`MEMOKET_DECIDE_TAP` 可换成 option/command/shift，默认避开 Claude 桌面端的 ⌥⌥）盯着修饰键，双击就弹出 macOS 原生的框选十字线（`screencapture -i`，要屏幕录制权限），药丸说「框一块屏幕」；松手后那块屏幕缩到 1600px 以内直接送进读图那条路（`origin: 'screenshot'`，剪贴板一个字都不碰），Esc 取消药丸静静复原。**⌥D**：在任何应用里选中一段文字（默认；被占就依次退到 ⌥J、⌃⇧Space，台面上显示实际生效的键；可用 MEMOKET_DECIDE_SHORTCUT 指定）。按下的一瞬间：光标处一圈强调色光环荡开（`cue.ts`：一个盖住显示器、不接鼠标的透明窗口，380 ms），岛的药丸改口「正在拿主意」。主进程一次 osascript 同时问前台是谁并模拟 ⌘C（之前先往剪贴板写一个哨兵；之后每 30 ms 看一眼，最多 450 ms）：剪贴板变了就是选区，没变就是什么都没选——这时用**当前这一次复制的内容**（不是历史）：文字直接走同一套；图片（缩到 1600px、6 MB 以内的 PNG）交给 Gemini 先读成一两句 digest 再出候选，Jev 按 digest 打分，台面上以缩略图 + digest 代替引文；Finder 里的文件这一期不接。读完把剪贴板放回：Electron 44 是 W3C 那套 clipboard（`read()` 给 ClipboardItem，`write()` 收 ClipboardItem），快照留下每一种类型（各应用的原生格式也在，不然 Numbers 的公式、Keynote 的幻灯片贴回去就没了），只跳过图片的派生格式（一张截图会带十几 MB 的 TIFF/HEIC/AVIF/PSD，只留一张 PNG），整份一次 write 放回；Finder 里 ⌘C 的是文件时（纯文字只是文件名）同样当没读到；整份放不回也至少把文字放回，哨兵绝不留在剪贴板上。岛**不在这时展开**：读到的那句摘录（或缩略图 + 来处）出现在药丸里，药丸在同一根弹簧上从 240 长到 320（收起的窗口平时和药丸一样 240 宽——透明的边会吃掉底下应用的点击；按下热键时主进程先把窗口放宽到 320，弹簧缩回 240 并 settle 时渲染层把停下的宽度报回来，主进程再收窄），一道光扫过；答案（或错误）到了渲染层才展开成「拿主意」的台面（面板 id `decide`，四个标签都不亮）——**被动展开，不抢焦点**（几秒后到的答案不能把键盘从别的应用手里夺走；人挪过来点一下或悬停，↑↓ ↵ 才接管）；什么都没读到只在药丸上说「没读到 · 先选中或复制」6 秒（上次的选项还在时，这样再按一次就把它们带回来）；没权限才展开，说去哪开。前台应用名一起交给岛。后端 `POST /api/desktop/decide`：召回 → Jev 的 Noul 判断「这段是不是要拿主意的事」与 Gemini 出候选**并行**（Gemini `thinkingLevel: minimal` 不先想——模型不收这个字段就去掉再发一次并记住，3–4 个候选、理由 ≤ 40 字，带知识库召回的事实，理由里引用 `[fact-id]`）→ Jev 的 Choice 估计用户**会选**哪个（问「会选」不问「该选」：后者会把 100% 押在一个上）；不是决定题就先反问三个「你可能想问的问题」，Jev 排序，选了再走后两步；连 digest 都没有时不问 Jev。整段从 9.4 s 降到约 4 s。台面：引用选区 + 来源应用，选项卡（一句选项、一句理由、概率条、事实小片），↑↓ 回车，动作只有记下来 / 变成待办 / 问 Claude 展开 / 复制，底部「补一句背景…」重跑。没有 Jev 密钥时概率是 Gemini 的估计并标「模型估计」；都没有就不显示数字。笔记的 AI 菜单里也有「拿主意」，对正文选区用同一套。 |
| 知识库（岛上不再单列） | 岛上「存入笔记」的每一篇都自动进知识库：存好后后台抽取事实（`POST /api/ingest/note/{id}/sync`），底部一行「已存入笔记 · 正在进入知识库」，抽完写「已进入知识库 · N 条事实」，知识库面板与「相关记忆」随即重取；抽不进去只提示，不影响已存好的笔记。搜索、导入、核对回到桌面端的知识库；岛上留下的是正文下方那条「相关记忆」。 |
| 暂存材料 | 在同一个顶部面板中放入文件、文件夹、图片、文字或链接。文件显示本机内容缩略图，可点开大图、打开、定位或原生拖出；文字显示实际摘录并可复制，链接可打开。 |
| 暂存剪贴板 | 明确点击后读取文字或图片；图片生成本机 PNG 副本。不会自动读取剪贴板历史。 |
| 窗口引用 | 主动列出窗口的实际画面截图，可先放大查看再暂存标题、ID 和静态预览；之后可尝试唤回原窗口。 |
| 使用暂存材料生成 | 从笔记的 AI 菜单选择「从暂存架选择」，勾选文字、链接摘录或已经本机读取的纯文本文件节选，在紧凑下拉框选择操作，再点「执行」。补充要求可选。执行后收起选材区域并在后台处理；明确点“查看结果”后预览正文、真实表格和 Mermaid 图形，可编辑、复制、追加正文或保存。 |

剪贴板候选仅在桌面随手记展开且页面可见时读取，约每 1.2 秒更新当前文字；收起或切换面板即停止，重新展开会重新读取。预览与正文使用相同排版，并跟随编辑区滚动；光标移到正文中间或选择文字时隐藏预览，避免遮盖原文或意外替换选区。尚未按 Tab 接入或明确用于 AI 处理的候选只在内存中，不保存历史、不创建笔记或暂存项，也不发送给模型。预览最多 12,000 个 UTF-16 代码单元，超长内容明确提示使用 `⌘V` / `Ctrl+V` 粘贴全文，禁用 Tab 接入与 AI 处理截断片段。Tab 仅在正文中有可接受的预览时生效，`Shift+Tab`、输入法组合与普通焦点导航保持原行为。继续输入或 Esc 会忽略本次候选；新复制的内容仍可出现。接入后成为当前本机草稿的一部分，仍需点击保存才成为笔记。

暂存架有内容时以物品为主，工具栏只保留数量、搜索图标与「添加」菜单。搜索框和文字输入在需要时展开，没有常驻类型筛选、文字表单或 AI 功能区；拖入文件时临时显示用途分区，不根据当前标签推测用户意图。新增暂存材料会清除旧查询，滚到最前面并短暂高亮；从新增完成起至少保留 3 秒展示结果，其间鼠标离开也不会立即收起。搜索时显示命中数与总数，避免把搜索结果误认为材料丢失。

收起后的药丸只说一件事，按优先级：投放结果（3 秒）→「AI 处理中」→「正在附加」→「正在拿主意」（热键刚按下；读到之后药丸长到 320，里面是那句摘录或缩略图 + 来处，答案到了才展开）→「没读到 · 先选中或复制」（6 秒）→「Claude 思考中」→「正在进入知识库」→「AI 已完成」→「选项已备好 · N 个」（收起时结果到了，几秒）→ 下一件没做完的待办（前面一枚小圆环，超过 12 字截断）→「今天的事都做完了」→「随手记」。药丸底沿一条细线是今天待办的完成比例。不再显示草稿标题。

Gemini 一次接受 1–12 项材料，标题、正文、网址和要求合计不超过 30,000 个字符。正文菜单按「选区 → 当前笔记正文 → 空稿时显示的剪贴板候选」确定来源，并保留打开菜单时的快照，不会自动合并草稿和剪贴板。没有可用内容时会提示先输入或复制。暂存架只发送手动勾选的文字、链接摘录与纯文本文件节选，不读取其他文件、图片、窗口或网页全文。链接没有摘录时会注明仅提供了链接，生成内容末尾由程序附上实际来源。

六种动作共享同一条可取消的生成路径。续写保留原文后追加新内容；图表和表格复用原仓确定性构造器，把模型返回的结构化数据渲染为 Mermaid/Markdown，结果预览复用原编辑器。这里不启动会自动写回的长文写作任务，也不改变完整笔记库的供应商设置。生成接口不保存笔记；只有「保存笔记」才写入现有笔记库，原材料与手动草稿仍保留。未保存生成稿可从「继续生成稿」恢复，重新打开不会自动重复调用模型。

## 文件与窗口边界

**笔记附件与暂存副本分别保存。** 拖入文件后，左侧目的地将文件复制为笔记资源，并把实际可用的资源链接保存在当前草稿；保存笔记时与正文一同写入。附件随草稿保留，收起、切换面板或重新展开不会丢失，上传失败会说明原因。这个操作不创建暂存项；右侧暂存操作也不向笔记添加附件或正文。拖入分区只在拖放期间显示，拖离后恢复原面板，未释放不会复制文件。两条路径均不移动或删除原件。

拖放移出使用短暂边界确认，跨左右区域或重新移入不会误取消；桌面端仅在文件拖入期间每 **120 ms** 查询原生光标是否仍在浮窗内，补偿 Finder 拖放可能缺失的退出事件。移出、Esc 或在外部结束拖放都会清除投放分区，未投放不创建附件或暂存副本；浮窗随后按正常离开规则收起。固定展开只保留浮窗，不保留已经结束的拖放分区。

**文件暂存采用独立副本。** 新拖入的文件或文件夹复制到当前桌面 profile 的 `companion/vault/<id>/`，保持原名，原件不移动或删除。复制和索引持久化成功后才显示成功卡片。原件随后改名、修改或删除不会影响这份快照。

旧版记录仍是原路径引用，启动时不会扫描并复制用户原文件；界面标明“含旧版引用”，重新拖入可创建新的独立副本。拖出交付的是另行准备的 export 副本，目标应用即使执行移动也不会移走暂存主副本。准备未完成会明确提示再次拖动，不会在鼠标释放后突然开始拖放；不把发起拖动当作目标接收成功，也不自动移除卡片。

每次最多导入 50 项、合计 512 MB / 2,000 个文件或目录，目录深度最多 16 层；符号链接和特殊文件明确拒绝。复制过程异步执行，源文件在复制中变化会中止本次导入，原件不受影响。

文件暂存与窗口选择在桌面浮窗内均按一行四个缩略图排列，名称在图下方；窄浏览器预览降为两列。文件卡片以内容预览为主，不用文件类型图标代替文档页面。macOS 使用系统 Quick Look 在本机生成缩略图，常见文档是否可预览取决于系统的预览支持；生成是后台任务，卡片区分生成中、就绪和无法预览。TXT、Markdown、CSV、TSV、日志读取前 16 KiB 原文直接展示，避免系统深色文本缩略图不清晰；内容按普通文字渲染，超长文件可打开副本查看完整内容（旧引用则打开原文件）。无法预览会显示原因，并可在放大面板中重试或用默认应用打开。文件夹与不支持的格式不会伪装成页面缩略图。

点击卡片预览区域，在同一个灵动岛内查看较大图片；文档、照片和窗口截图均按比例完整展示，文字卡片可看完整原文。Esc 先返回列表并还原焦点，再次按下才收起浮窗。预览区域依然支持文件或文字拖出；查看大图时移出仍按规则收起，再次展开保留预览。

文档预览缓存在桌面 profile 的 `companion/previews/`，使用原文件路径、大小与修改时间识别更新；不会修改原文件或把文件发给 AI。已有暂存引用会在启动或打开暂存架时补充预览。缓存使用受限并发与生成超时，删除暂存项目后迟到的预览任务不能恢复已移除项目。

新剪贴板图片也保存到 `companion/vault/<id>/clipboard.png`，索引为 `companion/shelf.json`。移除新副本会把它转入 `companion/removed/`，通过成功反馈的“找回副本”或菜单栏图标菜单里的“已移除的暂存文件…”打开；旧版引用只移除记录。已交付的 export 不复用、不依据推测的接收时机删除。暂存架按操作系统桌面 profile 保存，与笔记库中的用户切换是两个不同的范围。索引读取失败不会静默覆盖原记录；复制或索引写入失败不会显示成功。

窗口截图最高为 720×450，按实际窗口比例缩小，缺失截图会说明原因。刷新窗口列表后重新暂存同一窗口，会更新其保存的截图。窗口项是引用与静态预览，不会把 OS 窗口嵌入灵动岛，也不能恢复已关闭的应用会话。目前窗口列表与唤回适配 macOS：列出窗口前检查屏幕录制权限，唤回前还检查辅助功能权限；权限不足时说明原因，不主动请求授权。唤回会重新核对保存的窗口 ID 和完整标题，不重新截取预览。窗口关闭、改名、ID 失效或同名歧义时要求重新选择；其他系统会明确提示窗口功能尚不支持。

灵动岛不自动启用屏幕活动记录。Gemini 整理与完整笔记库原有的 AI 写作、知识库和屏幕活动能力分别配置，暂存材料不会自动触发模型处理。

## 开发运行与 Gemini 配置

先按 [完整笔记库开发说明](desktop-workspace.md) 准备 Python 虚拟环境、前端依赖，再安装桌面依赖。桌面版读取构建后的前端，不会通过 `npm run dev` 自动启动 Vite：

```sh
# 仓库根目录
npm --prefix desktop ci
npm --prefix frontend run build
npm --prefix desktop run build
```

同一份 Gemini 凭据也给知识库的事实抽取用：设置页没填本地模型、`.env` 也没给 `LLM_BASE_URL` 时，抽取走 Gemini 的 OpenAI 兼容端点（`/api/health` 的 `llm.source` 为 `gemini`），岛上存的笔记才进得了知识库；明确配了本地模型或 GPT 的仍以那个为准。Jev 密钥由 `JEV_API_KEY` 或 `MEMOKET_JEV_KEY_FILE`（仅含密钥的本机私密文件，项目约定放在 `.local/secrets/jev.key`）提供；没有也能用，只是概率退成模型估计。Gemini 凭据由启动环境中的 `GEMINI_API_KEY` 提供，或由 `MEMOKET_GEMINI_KEY_FILE` 指向一个仅包含密钥的本机私密文件；两者同时存在时优先使用 `GEMINI_API_KEY`。密钥仅供后端读取，不会返回给前端。`GEMINI_MODEL` 可覆盖模型名，目前默认 `gemini-3.5-flash`，该模型已于 2026-09-22 通过一次真实 `generateContent` 请求（HTTP 200）；模型可用性仍取决于当前账号与服务状态。

下例中的路径需要替换为自己的私密文件。若启动环境已提供 `GEMINI_API_KEY`，可省略文件变量：

```sh
MEMOKET_GEMINI_KEY_FILE=/absolute/path/to/private/gemini-key \
GEMINI_MODEL=gemini-3.5-flash \
MEMOKET_USER_DATA=/private/tmp/memoket-layer-review/userdata \
KITE_DATA_DIR=/private/tmp/memoket-layer-review/data \
  npm --prefix desktop start
```

`MEMOKET_USER_DATA` 在开发模式下隔离桌面 profile；`KITE_DATA_DIR` 指定隔离笔记数据。没有 Gemini 配置也可使用记录、专注与原生暂存；整理入口会说明尚未配置。`GET /api/desktop/ai-status` 只返回 `configured`、`model`、`provider`，其中 `configured` 表示已读到配置，不代表已经成功生成。

默认不打开完整笔记库。显式传 `--workspace` 可使用完整窗口，旧的 `--probe`、`--shot` 保持完整笔记库验收兼容。同一 profile 已有实例时，Electron 会激活该实例；修改代码后应退出自己的测试实例，再启动新构建。

## 浏览器交互预览

```sh
bash scripts/dev-workspace.sh
```

打开 [顶部灵动岛预览](http://127.0.0.1:5178/?user=ui-review&surface=preview)。它使用同一个 React 顶部组件，记录连接真实本地笔记接口，专注使用本机计时；新数据目录没有预置材料或演示笔记。浏览器没有原生暂存桥接或自动剪贴板候选，文件路径、系统剪贴板图片、跨应用拖出、窗口权限与唤回必须在桌面版验收。浏览器中的展示不能证明 OS 操作已成功。

## 测试与验收

```sh
# 仓库根目录：桌面构建、暂存/边界/窗口适配的模拟回归
npm --prefix desktop test

# 前端交互回归：使用模拟桥接，不读取系统剪贴板；知识库面板与相关记忆条另有一套，召回接口用假的
cd frontend
npm exec -- vitest run src/components/__tests__/desktopCompanion.test.tsx src/components/__tests__/companionKnowledge.test.tsx

# 后端独立生成接口回归，不调用真实 Gemini
cd ../backend
PYTHONPATH=. .venv/bin/pytest -q tests/test_desktop_notes.py
```

自动测试使用临时文件、虚构测试凭据和模拟窗口依赖，不读取真实桌面或调用真实 Gemini。实际交互需另行核对：

1. 在其他应用中输入，悬停顶部展开时仍保持原应用焦点；移开后按规则收起。
2. 首次展开确认进入笔记，核对剪贴板预览，按 Tab 接入当前草稿后明确保存；从完整笔记库搜索并读回。验证 Shift+Tab、输入法和长内容不会误接入，保存失败时输入仍保留。切到暂存架后收起并再次悬停，确认保留当前面板；全局快捷键仍直接打开笔记。
3. 用临时文件分别拖到左、右目的地；释放前移出一次，确认分区取消且两处均未新增。左侧成功后核对附件可打开、暂存数量不变，收起再展开草稿附件仍在；保存后从笔记库读回真实资源链接。右侧成功后核对笔记未变、新暂存卡片可见且总数正确；已有搜索时加入文件同样可见，文档显示真实页面、图片显示实际图像。点开大图后 Esc 返回，再拖到目标应用，确认目标实际接收，并核对源文件位置。另用临时文件验证：改名或删除原件后副本仍可读；移除暂存副本后可从已移除文件夹找回。不能用预览成功代替副本验收。
4. 在正文中选择一段文字并右键，确认菜单标明选区；取消选区后从底部 AI 菜单处理当前笔记，空稿时核对使用的是显示的剪贴板候选。另在暂存架勾选文字和链接、选择操作并执行；检查结果与来源、修改草稿，再明确保存。生成成功和保存成功分别确认。使用延迟响应检查生成期间继续编辑、切暂存架、调用拖出、切专注和收起；完成不跳当前页面，重新展开不重复请求。显式插入时保留生成期间新增的正文和原标题；取消后迟到响应不得写入草稿。
5. 重启测试实例，核对暂存副本和旧引用、随手记草稿及整理草稿恢复。
6. 在已授权的 macOS 上检查窗口实际截图，点开大图、暂存，再切走后唤回；关闭或改名后再唤回，应明确提示失效。
7. 在工作台启动专注，再回顶部面板暂停、继续；收起后倒计时仍更新，另一用户的计时不被更改。

OS 拖放接收、跨应用焦点与系统权限不能用模拟测试通过代替；Gemini 返回草稿也不等于笔记已保存。

动效另做三组验收，建议录屏后逐帧检查；这些是验收标准，不代表已完成真实系统验收：

1. **可打断与及时响应**：快速经过顶部不足 120 ms 时不展开；在展开与收起约三分之一、三分之二处移开或重新进入。轮廓应从屏幕上的当前位置连续反向，不能跳到端点、先停一拍或等旧动画完成；运动中仍可点击入口。
2. **内容与空间稳定**：用多行文字和已有输入的草稿观察中间帧。顶部中心锚点保持不变，文字行数、字号与光标位置不因轮廓变化而抖动；内容分层显隐不闪出旧面板。悬停不抢原应用焦点，运动中点击或使用快捷键仍可继续输入。
3. **完整收尾**：原生画布只在渲染层收起完成后缩小；收起途中重开后，旧完成通知或超时不能再次缩窗。开启减少动态效果、暂时暂停渲染帧后恢复，也应回到正确状态，最终不能留下透明大窗挡住底下应用。
