# 知识库体验：设计与 200 轮执行计划

> 触发：布局重梳理之后，「整个知识库部分的体验完全缺失，可视化、查询等都没有了」。
> 上一版把知识库拆成树上的节点是对的（每个元素一个家），但节点打开之后**里面是空的**：
> 「知识库」根节点是一列子分类、主题页是一列事实、时间线是月份列表、搜索没了。

## 1. 原则（延续 layout-redesign-plan）

1. **知识库的每个节点打开都是一页有设计的「只读笔记」**——不是列表，是页面：
   有头（数字）、有图（时间/分布）、有关系（邻居）、有动作（引用/插入/开分屏）。
2. **查询有三个入口，一个都不藏**：根节点的搜索框（首页第一屏）、事实表（可过滤）、
   ⌘K（笔记 + 知识库合一）。
3. **图是读的，不是装饰**：按 dataviz 的规矩——单色序列表示数量（accent 一种色，
   浅→深），细 mark、圆角端、hover 有值、文字用文字色。不用彩虹。
4. **风格跟当前一致**：Boxicons、`--accent`、卡片 `--panel` + `--line`、12px muted 说明、
   跟笔记页同一个标题行 / 面包屑 / 标签页。

## 2. 每个节点长什么样

| 节点 | 页面 |
|---|---|
| **知识库**（根） | 首页：搜索框（即搜即显，结果可开事实 / 插入引用）· 五个数字块（事实 / 主题 / 实体 / 会议 / 跨度）· 近 12 个月的事实条形图 · 最近摄入（会议）· 主题 Top（含闭包计数，点开）· 实体 Top · 抽取质量 / 覆盖度一行 |
| **主题**（分类页） | 主题树（一级主题卡片：计数 + 子主题数）；点开进主题页 |
| **主题页** | 头（code · 别名 · N 条事实 · 父主题面包屑）· 月度条形图 · 子主题 chips · 共现实体 chips · 事实列表（按月分组，每条：日期 · 说话人 · 引用 / 打开） |
| **实体**（分类页） | 按事实数排序的实体网格（名字 · 类型 · 计数），可搜 |
| **实体页** | 头（名字 · 类型 · 别名 · N 条）· 关系（rel → 目标，可点）· 月度条形图 · 相关主题 chips · 事实列表 |
| **时间线** | 纵向时间线：月 → 日，条形表示当天事实数，点开一天展开事实；顶部年份跳转 |
| **最近摄入** | 会议卡片列表（日期 · 标题 · N 条事实 · 说话人），点开会议页（这场会抽出来的事实） |
| **事实表** | 表格 + 一行过滤器（类型 / 说话人 / 主题 / 实体 / 置信度 / 日期）· 分页 · 每行可开 / 引用 |
| **主题地图** | 现有 d3 力导向图，控件换成当前样式、随容器宽、暗色配色 |
| **总览** | 并入首页（删掉独立节点） |
| **定期回顾** | 保留，样式对齐 |
| **事实页** | 已有；补：主题 / 实体 chips 可点、「引用到最近编辑的笔记」 |

## 3. 后端

一个纯逻辑模块 `app/database/kb/pages.py`（跟 `virtual_tree.py` 同一纪律：只读
`mem._index()`，不碰 I/O，手搭 Store/Vocab 就能测）：

- `dashboard(mem)`：数字 · 月度计数（近 12 个月）· 主题 Top（闭包）· 实体 Top ·
  最近会议 · kind 分布
- `topic_page(mem, code, limit, offset)`：头 · 子主题 · 月度 · 共现实体 · 事实（分页）
- `entity_page(mem, code, limit, offset)`：头 · 关系 · 月度 · 相关主题 · 事实
- `timeline(mem)`：月 → 日 计数
- `unit_page(mem, unit_id)`：一场会议的事实 + 说话人

路由：`GET /api/kb/dashboard` · `/kb/topic/{code}` · `/kb/entity/{code}` ·
`/kb/timeline` · `/kb/unit/{id}`。事实表继续用 `/api/memory/facts`。

## 4. 前端

`KbNoteView` 按 id 派发到：`KbDashboard` · `TopicPage` · `EntityPage` ·
`TimelinePage` · `UnitPage` · `FactsTable` · `GraphPage`（包 KnowledgeGraph）·
分类页（主题 / 实体 / 最近摄入）。公共小件：`MiniBars`（单色条形图，hover 有值）、
`StatTile`、`Chip`、`FactRow`（日期 · 说话人 · 文本 · 引用 / 打开）。
